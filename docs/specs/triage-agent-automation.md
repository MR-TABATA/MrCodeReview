# 初期仕分け自動化とエージェント連携の自動投入

- 作成日: 2026-11-19
- 状態: 下書き

## 目的
レビュー結果の仕分けとエージェントへの修正依頼における手動作業を自動化し、レビューから修正着手までの手数を削減する。

## 決めたこと
- config で「High と Medium は対応する」を設定できるようにする
  - なぜ: （会話に理由なし）
- Low は自動で仕分けず、確認のためにそのまま（未仕分け）にする
  - なぜ: 人間が確認するため。
- レビュー結果が出た時点で、High と Medium は仕分けされている状態にする
  - なぜ: （会話に理由なし）
- Low に対して「無視」と「対応」のワンクリックボタンをそれぞれ置く
  - なぜ: （会話に理由なし）
- config でエージェントを登録できるようにする
  - なぜ: （会話に理由なし）
- 登録したエージェントへワンクリックでタスクを投入できるようにする
  - なぜ: ターミナルを開いてコピペする手動作業をなくすため。

## やらないこと
- 修正から再レビューまでの完全自動ループ（無人自律ループ）
  - なぜ: 無限修正ループやトークン爆発のリスクがあるため。

## タスク
1. config（設定）に重大度ごとの初期仕分けポリシー（High/Medium を自動で「対応」、Low は未仕分け）を追加する
   - 触るファイル（見込み）: `app/src-tauri/src/settings.rs`、`app/src/settingsmodel.ts`、`app/src/settingsui.ts`
2. レビュー完了時に初期仕分けポリシーを適用し、High/Medium が「対応」になった状態で画面に表示する
   - 触るファイル（見込み）: `app/src/main.ts`、`app/src/store.rs`
3. 未仕分けの Low に対して「すべて対応」「すべて無視」をワンクリックで行うボタンを画面に配置する
   - 触るファイル（見込み）: `app/src/fixall.ts`、`app/src/main.ts`
4. config（設定）にエージェント定義（名前・コマンド・引数テンプレート・起動方式など）を登録できる仕組みを追加する
   - 触るファイル（見込み）: `app/src-tauri/src/settings.rs`、`app/src/settingsui.ts`
5. 画面上の handoff 領域に登録済みエージェントのワンクリック投入ボタンを配置し、押したときにエージェントを直接キックする
   - 触るファイル（見込み）: `app/src/handoffview.ts`、`app/src/main.ts`、`app/src-tauri/src/lib.rs`

## 受け入れ基準
- レビュー完了時、config 設定に基づき High と Medium が最初から「対応」に仕分けされている（確かめ方: レビューを実行し、結果表示時に High/Medium が「対応」状態になっていることを目視確認する）
- Low が存在する場合、「Low をすべて対応」「Low をすべて無視」のボタンが表示され、1 クリックで仕分けが完了する（確かめ方: ボタンをクリックし、Low の仕分け状態が一括で変わることを目視確認する）
- config に登録したエージェントのボタンが表示され、クリックするとターミナルまたはプロセス経由でエージェントに handoff が渡って起動する（確かめ方: ボタンをクリックし、エージェントがタスクを読み込んで起動することを確認する）

## 未決事項
- エージェント起動の実行方式（macOS の Terminal.app / iTerm2 で別ウィンドウや別タブを開くか、MCR のバックグラウンドサブプロセスとして動かすか）
- エージェント登録設定の UI（設定画面の「連携」タブで入力するか、設定ファイル直接編集のみとするか）
- レビュー再実行時の初期仕分けの挙動（2周目の「前回の続きから」レビューで、前回の仕分け引き継ぎと初期仕分け設定の優先関係）
